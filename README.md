# 武汉地铁 8号线 · 下一趟

一个轻量的网页，用来看武汉地铁 8 号线某站**下一趟车还有多久到**。纯静态页面 + 一个只用 Node 内置模块的静态服务器，没有构建步骤、没有第三方依赖。

- 26 个站点按线路顺序排列，标注换乘线路
- 两个方向可一键切换，按钮上直接显示各自还有几分钟
- 大号倒计时（分:秒）+ 列车沿轨道行进的进度条
- 自动区分工作日 / 休息日（首班 6:00 / 6:30）
- 全天发车时刻表，按小时分组，自动高亮当前班次
- 定位推荐最近车站（需本机 `localhost` 或 HTTPS，见下文）
- 与站台显示屏有偏差时，可整体 ±10 / ±30 秒校准

## 快速开始

### 本地运行（需要 Node 18+）

```bash
npm start          # 或 node server.js
```

Windows 也可以直接双击 `start.bat`，会自动打开 <http://localhost:8788>。
没有 Node 时 `start.bat` 会退回 Python 的 `http.server`。

也可以直接双击 `index.html`：站点、方向、倒计时都能用，只有"定位"会被浏览器拦截。

### Docker

```bash
docker build -t wuhan-metro-line8 .
docker run -d -p 8788:8788 --name line8 wuhan-metro-line8
```

或者用 compose：

```bash
docker compose up -d
```

打开 <http://localhost:8788>。镜像基于 `node:20-alpine`，监听 `0.0.0.0:8788`，带 `HEALTHCHECK`，以非 root 用户运行。可用环境变量 `PORT` / `HOST` 覆盖默认值。

```bash
docker run -d -p 9000:9000 -e PORT=9000 wuhan-metro-line8
```

## 局域网访问（用本机 IP 打开）

`server.js` 默认监听 `0.0.0.0`，启动后会把可用的局域网地址打印出来：

```
  本机访问   http://localhost:8788     （可直接定位）

  同一 WiFi 下的手机 / 平板：
             http://192.168.1.100:8788     (以太网)
```

手机连同一个 WiFi，打开 `http://192.168.1.100:8788` 即可，无需安装任何东西。

几点说明：

- **本机 IP 会变**：换网络后以启动时终端打印的为准，不用改代码。
- **手机打不开**：多半是 Windows 防火墙拦了入站。以管理员身份运行 `firewall.bat` 放行 TCP 8788（仅专用网络），或在"Windows 安全中心 → 防火墙 → 高级设置"里放行 Node。
- **手机上定位不可用**：浏览器规定只有 HTTPS 或 `localhost` 属于"安全上下文"，`http://192.168.x.x` 会直接禁用 Geolocation（W3C 规范，页面无法绕过）。手机上请直接点站点框手动选站，**选一次会记住**，下次打开还是这个站。
- **换端口**：`set PORT=8790 && node server.js`；只想本机访问：`set HOST=127.0.0.1 && node server.js`。

## 数据说明

发车时刻**不是**官方实时数据（武汉地铁未开放实时到站接口），而是按官方公布的时刻参数推算：

| 参数 | 取值 | 来源 |
|---|---|---|
| 两端首班 | 工作日 6:00，休息日 6:30 | 武汉地铁官网 |
| 两端末班 | 23:00（全程约 68 分钟） | 武汉地铁官网 |
| 工作日高峰间隔 | 4.8 分钟 | 武汉地铁公开信息 |
| 周末最小间隔 | 6.3 分钟 | 武汉地铁公开信息 |
| 各站运行时间 | 由官网末班车时刻序列反推 | 武汉地铁官网《8号线各站首末班车时间》 |
| 各站坐标 | OpenStreetMap `railway=station` 节点 | OSM contributors |

推算方式：从起点站按首末班与分时段间隔逐班生成发车时刻，再叠加"起点站 → 本站"的运行分钟数，得到本站到站时刻。

官网首班车一列存在滚动发车与版面错位，因此各站运行时间取自**末班车**时刻序列——该序列严格递增且自洽，可直接作为基准。

**因此：**

- 与站台显示屏通常相差 1 分钟以内；
- 不含临时加开、小交路、节假日专项方案、故障延误；
- 遇到大幅调整，请以车站广播和官方 App 为准。

车站坐标为 OSM 实测值（精度约 10–50 米），仅用于推荐最近车站。
